# vector-memory
This repository contains the implementation of the methods presented in article [1].
Method A contains a Julia implementation of the Lanczos based algorithm, Method B contains a Matlab and Python implementation of the algorithm based on rational approximation and least-squares optimization.

The script that reproduces the graphics from the paper can be found in Method A.

# Using the Code
If you want to use this code for your own project, we highly recommend reading the article [1] to get a better understanding of the underlying theory, since the algorithms are highly sensitive to changes in the input data and parameters used.

# References
[1] Bockius N., Braun M., Hofmann K., Schmid F. and Hanke M., Determining extended Markov Parameterizations for vector-valued generalized Langevin equations, Zeitschrift für Naturforschung A. (DOI: 10.1515/zna-2025-0354)
